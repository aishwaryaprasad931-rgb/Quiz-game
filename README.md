🧠 Simple Quiz Game

A simple beginner-friendly quiz game created using HTML and CSS.

📌 About the Project

This project is a basic quiz webpage where users can read a question and select an answer from multiple options.

It is created to practice the basics of HTML forms, radio buttons, buttons, and CSS styling.

🛠️ Technologies Used

- HTML
- CSS

✨ Features

- Simple and clean design
- Multiple-choice question
- Radio button options
- Responsive and beginner-friendly layout
- Styled using CSS


📚 What I Learned

- Creating HTML forms
- Using radio buttons
- Structuring webpage content
- Styling elements with CSS
- Using CSS hover effects
- Connecting HTML with CSS
